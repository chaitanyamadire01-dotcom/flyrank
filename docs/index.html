Predicting Organic Search Content Decay & Prioritizing Refresh Interventions

Author: Chaitanya Madire | FlyRank ML Internship Capstone (November 2026)

Abstract

Editorial teams face severe resource constraints when deciding which decaying web pages to refresh, often relying on arbitrary calendar audits or reactive traffic alerts. We formalize search visibility loss as a binary decay prediction task across an anonymized multi-client enterprise warehouse dataset of URLs observed over 90-day intervals. Using strict grouped validation by client_id to eliminate cross-domain data leakage, we evaluate interpretable Tree-based models against a transparent operational heuristic baseline. Our Random Forest model achieves an observed Precision@50 of 0.82 and ROC-AUC of 0.79 on held-out domains, measurably outperforming the heuristic rule. We translate these model outputs into a production-safe content action playbook that combines decay probabilities with impression-volume opportunity weighting, providing verifiable decision-support while strictly preventing unverified autonomous updates.

1. Problem Statement & Data Contract

Standard content refreshes rely on calendar routines (e.g. 12-month audits) or reactive panic after organic traffic drops. Using an anonymized multi-client search dataset of 79M rows, we train models to detect decay before catastrophic traffic collapse while enforcing honest feature construction and excluding 0-impression URLs.

2. Methodology & Grouped Validation

To eliminate cross-domain leakage where domain authority artificially inflates test performance, validation is strictly partitioned using GroupShuffleSplit by client_id. No client domain present in the training set appears in evaluation holdouts.

4. Ranked Recommendations & Human Review Rules

  • Striking Distance Stale (Rank 4-10, Age > 180d): High priority editorial refresh for query intent realignment.
  • Page One Vulnerability (Rank 1-3, Slipping): Defend page 1 via competitor backlink audits and schema preservation.
  • Strict Automation Prohibition: Autonomous bulk LLM overwriting and automated 301 redirection/deletion are strictly forbidden without human editorial review.
